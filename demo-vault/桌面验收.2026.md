# 墨砚桌面验收样例

请在示例库副本中操作；本页是检查步骤，不是验收结果。快捷键使用 [[欢迎|欢迎页]] 中对应平台的默认值，自定义绑定以设置为准。

## 写作与保存

中文 English 😀 👩‍💻 é

**粗体** 和 `代码`。

1. 新建笔记，输入中文、表情和组合字符，确认候选框位置、提交及取消行为。
2. 切换实时预览、源码模式和阅读视图，确认正文没有因模式切换变化。
3. 修改正文并撤销、重做；手动保存后关闭重开，确认内容一致。
4. 使用快速打开和全文搜索找回笔记。

## 草稿恢复

1. 在测试笔记中添加一段新内容，不执行正式保存，等待草稿后台持久化。
2. 仅对测试实例执行强制退出；重启并打开同一测试笔记库。
3. 从空标签页或命令面板打开“文件恢复”，比较草稿后恢复为副本。
4. 检查原文件仍是正式保存版本，副本包含最近已持久化内容。尚未持久化的末尾输入可能丢失。

## 布局与键盘

- 将窗口缩到最小尺寸，再放大界面字体，检查主要设置页说明换行、自动同步开关和底部按钮是否可见或可滚动到达。
- 用键盘完成建库、新建、保存、搜索和打开恢复入口；记录无法聚焦、焦点顺序异常或没有名称的控件。
- 自定义一个快捷键，再清空和恢复默认，检查菜单提示与实际触发一致。
