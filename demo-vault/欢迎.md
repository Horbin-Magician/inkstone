# 欢迎使用墨砚

这是墨砚（InkStone）自带的示例笔记库。建议先复制整个 `demo-vault` 文件夹，再打开副本体验，保留原示例以便对照。

## 写下第一篇笔记

1. 在欢迎页选择“创建新笔记库”，指定一个尚不存在的文件夹；已有 Markdown 文件夹可直接通过“打开已有笔记库”打开。
2. 在空标签页选择“创建新笔记”，输入名称后开始写作。也可以使用下表中的新建笔记快捷键。
3. 写作后手动保存。Markdown 文件保存在本地，可以用其他文本编辑器打开。
4. 使用“查找笔记”或全文搜索找回内容。试试 [[示例/格式检查|格式检查]]，也可以点击尚不存在的 [[我的第一篇笔记]] 创建笔记。

## 三种编辑方式

通过笔记顶部的模式菜单切换：

- **实时预览**：边写边看排版，编辑时按光标位置显示相关 Markdown 源码；复杂内容的展示和编辑方式可能不同。
- **源码模式**：直接查看和编辑 Markdown 标记，适合调整表格、链接和复杂语法。
- **阅读视图**：浏览排版后的正文、列表、代码、表格和本地图片，不修改正文。

## 默认快捷键

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 新建笔记 | Cmd+N | Ctrl+N |
| 查找并快速打开笔记 | Cmd+O | Ctrl+O |
| 命令面板 | Cmd+P | Ctrl+P |
| 全文搜索 | Cmd+Shift+F | Ctrl+Shift+F |
| 当前文档查找 | Cmd+F | Ctrl+F |
| 查找并替换 | Cmd+Alt+F | Ctrl+H |
| 保存更改 | Cmd+S | Ctrl+S |
| 切换阅读视图 | Cmd+E | Ctrl+E |
| 新标签页 | Cmd+T | Ctrl+T |
| 下一个标签页 | Ctrl+Tab | Ctrl+Tab |

这是默认值；已有自定义快捷键保持有效。以设置中的“快捷键”和界面提示为准。Linux 列说明配置规则，不代表已完成 Linux 原生验收。

## 保存与恢复

正文不会定时自动保存。应用会在后台为已提交的编辑写入独立恢复草稿；输入法仍在组词的预编辑不属于已提交正文。最近尚未持久化的输入在意外退出后仍可能丢失，因此写作中请及时手动保存。

意外退出后，打开命令面板，选择“文件恢复（草稿、历史、回收站、同步备份）”；空标签页也有“文件恢复”按钮。在恢复入口比较草稿、恢复为副本或放弃恢复。恢复副本保留现有文件，正式保存成功后对应草稿会清理。

需要整库备份时，在设置中选择备份位置。整库备份的查看、恢复和清理与单篇笔记恢复分开；清理需要预览和明确确认。草稿、版本历史及同步不能替代独立备份。
