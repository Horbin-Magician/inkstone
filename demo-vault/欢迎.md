# 欢迎使用砚台

这是一个用于运行与验证的示例笔记库。你可以直接修改本目录的 Markdown 文件。

## 三种编辑方式

- **限定实时样式**：标题、粗体、`行内代码` 和双链；标记隐藏保留原位置宽度。
- 源码：所有 Markdown 都可以直接编辑。
- 阅读预览：渲染列表、引用、代码、表格和本地图片。

[[示例/格式检查|打开格式检查]]，或者创建 [[我的第一篇笔记]]。

## 键盘

Ctrl+P 快速打开，Ctrl+Shift+F 全文搜索，Ctrl+F 文档查找，Ctrl+S 保存。

Ctrl+Enter 跳转光标所在双链；Ctrl+点击双链调用组件定义跳转接口（待桌面回归）。
