# 墨砚

Rust + GPUI 本地 Markdown 笔记应用。正在按本机 Obsidian 1.13.7 对齐 UI 与基础功能，整体目标尚未完成。当前实现及剩余差距见 [对齐清单](docs/OBSIDIAN_PARITY.md)。

### 本轮新增

- 合并标题栏与标签栏，深灰/浅色三栏工作区，可折叠、拖动调整侧栏。
- 标签拖动排序、固定、关闭后重开，前进/后退，书签，打开笔记与设置恢复。
- 可搜索命令面板、方向键操作的快速切换、文件右键菜单。
- 工作区命令快捷键可搜索、录入、清除和恢复默认，提示冲突并随笔记库保存。
- 空文件夹、文件夹移动与回收站恢复；文件和文件夹移动更新双链、Markdown 链接及本地附件引用。
- 自动更新内部链接可配置；默认在重命名或移动后询问，支持不更新、仅本次和始终更新。
- 复制笔记到同目录并自动编号，打开副本，同时保留原标签及未保存编辑。
- 可设置新笔记和附件的存放位置，支持当前目录/指定目录，附件另支持相对子文件夹。
- 内容区域直接显示笔记正文，文件名保留在标签栏和顶部路径中。
- 笔记双链补全支持最短路径、相对路径和库根路径设置，同名笔记保留必要目录。
- 笔记补全保留完整路径搜索，可设置生成双链或标准 Markdown 链接，并处理 URL 特殊字符。
- 链接补全支持笔记别名，插入时保留显示别名并指向真实笔记。
- `#` 标题和 `#^` 已有块标识可补全，支持当前笔记内引用及 Markdown 片段编码。
- 文件树支持名称、修改时间、创建时间双向排序，文件夹优先，名称中的数字按数值顺序比较。
- 文件浏览器可自动展开并定位当前笔记，也可通过命令手动显示当前文件。
- 搜索支持 `file:`、`path:`、`tag:`、引号短语、排除词、`OR` 与 `/正则/`。
- 标签、别名、引用式链接反链、块引用、基础属性编辑。
- 阅读任务勾选与 Ctrl+L 任务格式，整篇/章节/块嵌入、正确的相对链接来源及图片尺寸参数。
- 阅读 Callout 支持类型样式、嵌套、标题链接和折叠，隐藏正文的跳转会自动展开。
- 命名脚注按引用顺序显示上标与文末内容，支持点击往返及嵌入笔记同名脚注隔离。
- 插入脚注命令自动编号，保留选中正文并追加文末定义，引用和定义可一步撤销。
- 新脚注在浮动编辑窗中输入，支持多行回写、撤销和 Escape 返回正文；输入法及来源冲突保留待处理内容。
- 已有脚注可通过“编辑光标处的脚注”命令或编辑器定义跳转重新编辑，保留后续正文与引用位置。
- 列表/任务/引用回车续写、空项退出、Tab 缩进和前缀退格；结构编辑可一步撤销。
- 选区可切换粗体、斜体、删除线、高亮和行内代码，保留嵌套格式与撤销选区。
- 提供正文/六级标题、引用、列表和代码块命令，支持选中多行转换。
- 源码表格支持 Tab 单元格导航、末尾新增行、增删行列及对齐命令，可单步撤销。
- 编辑区标题/列表/引用/代码块折叠，搜索和大纲跳转自动展开；各视图折叠状态随会话恢复。
- 附件选择/拖放导入、剪贴板图片粘贴；同名附件自动编号。
- 附件导入遵循链接路径和双链语法设置，短文件名可匹配库内唯一附件，同名文件保留必要目录。
- 双链补全可搜索图片、PDF 和音视频附件，保留目录显示与原扩展名。

已有源码、实时预览、阅读三种模式。实时预览接入图片、表格、Callout、嵌入、公式与图表的源码投影；公式和 Mermaid 使用纯 Rust 原生图形，脚注与常用 HTML 已补齐。支持范围和剩余验收见 [Markdown 支持矩阵](docs/MARKDOWN_SUPPORT.md)。新增功能的自动测试与原生界面验证范围分别记录，不能把编译通过当作桌面验收。

## 运行

已有可执行文件：`target/release/inkstone.exe`。从本仓库目录运行：

```powershell
.\target\release\inkstone.exe .\demo-vault
```

打开自己的笔记库：

```powershell
.\target\release\inkstone.exe "D:\我的笔记"
```

也可以不传参数，启动后用“打开笔记库”选择文件夹；应用记住最近的库。

## 构建与验证

测试环境：Windows 11、Rust 1.98.1、Visual Studio 2022 C++ Build Tools + Windows SDK。

```powershell
cargo build --release --locked --bin inkstone
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo fmt --check
cargo run --release --locked --example benchmark -- 10000
```

macOS 开发启动使用 `cargo run --locked --bin inkstone`，可执行文件内嵌应用名称配置，系统菜单显示“墨砚”。打包为可双击启动的应用：

```sh
bash scripts/bundle-macos.sh
open target/debug/墨砚.app
# 发布构建：bash scripts/bundle-macos.sh --release
```

打包脚本使用本机临时签名，尚未配置发行签名和公证。当前界面固定为中文；将来切换界面语言时，需同步更新 `packaging/macos/Info.plist` 中的系统显示名称。Linux 尚未构建或验收。

## 双链规则

- `[[笔记]]`：优先同目录；否则按全库同名匹配，唯一时跳转，多个时显示歧义并要求选择。
- `[[目录/笔记]]` 或 `[[/目录/笔记]]`：相对库根目录。
- `[[../笔记]]`：相对当前文件目录，不能越出库。
- 支持 `[[笔记|显示名称]]` 和 `[[笔记#标题]]`。
- 重命名文件会更新能解析到该文件的双链与标准 Markdown 链接；保留显示标签、标题片段和其他原文。每个文件保存前检查冲突，部分失败会明确提示。文件夹移动同样支持更新引用路径，并遵循内部链接更新设置。
- 带点的名称（如 `[[会议.2026]]`）对应 `会议.2026.md`。
- 普通 `[文本](路径.md)` 相对当前文件目录解析，支持中文 URL 编码；目标不存在时提示错误，不自动建笔记。

## 数据与恢复

Windows 应用数据在 `%LOCALAPPDATA%\Inkstone`。`recovery` 保存 JSON 恢复记录（包含正文），成功记录后缀为 `.saved`，失败 / 崩溃记录为 `.json`。界面提供每篇文件最新恢复草稿，恢复时新建笔记，不覆盖原文件。历史记录暂不自动清理。

删除会移动到笔记库的 `.inkstone-trash/<编号>/`，同目录有 `original-path.json`。可在命令面板的“查看回收站”中恢复文件与文件夹；原路径已存在时拒绝覆盖。

冲突时自动保存停止；“另存为副本”可保存当前编辑版本。普通保存错误也会停止自动重试，修复原因后按 Ctrl+S。IME 组词期间不会把预编辑拼音自动保存。异常退出仍可能丢失尚未写入恢复区的输入；慢速 IO 或组词期间可能超过一个自动保存周期。

## 实时预览边界

标题与常用文字语法使用源坐标样式；图片、表格、Callout、嵌入、公式及图表使用可变高度展示投影，光标或选区进入时展开源码。表格复用源码 Tab 导航和行列命令，图形采用后台资源缓存。展示、复制、保存和撤销保持原始 Markdown；视觉对齐、原生多 DPI 与富内容性能目标仍待完成验收。
