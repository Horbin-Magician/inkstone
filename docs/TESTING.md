## Release 后台基准

命令：`cargo run --release --locked --example benchmark -- 10000`。

样本在 C: 临时目录，程序生成后立即测量，没有清空 OS 缓存；各数据是一轮测量，不是百分位统计。

| 工作负载 | 结果 |
| --- | --- |
| 10,000 篇笔记，每篇 146 字节，首次逻辑索引 | 10,640 ms（另一次 11,836 ms） |
| 全文搜索常见词，命中前 200 条即停止 | 0.161 ms |
| 全文搜索不存在词，遍历全部文档 | 5.659 ms |
| 反链查询，样本全部指向同一篇 00001.md | 6.252 ms，10,000 条 |
| 单文件更新，包括整个内存索引复制 | 6.136 ms |
| 单篇 3,500,013 字节中文 / 英文 / emoji 长段落 AST 解析 | 309 ms（另一次 311 ms） |

一万篇首次索引成本偏高。普通文件事件已改为更新对应文件，目录事件仍重建。以上不是 UI 输入延迟、滚动帧率或最坏情况承诺。
