## 产品完善路线（2026-10-03）

用户已授权依次实施。按可独立验证的改动检查、提交，不混入用户笔记。

1. **编辑性能与输入稳定性（进行中）**：普通段落增量解析已实现；长文换行/文本修改、release 原生基准、跨平台输入法及多 DPI 验收仍待完成。
2. **版本历史与冲突处理（主要功能已实现）**：已实现按笔记的历史时间线、保存前/记录正文、差异预览和恢复副本；外部冲突比较、保留本地/采用磁盘、处理前草稿备份与并发变化保护；整库手动/每日/每周备份、SHA-256 校验及恢复到新目录。历史恢复、冲突比较、整库备份恢复已完成 macOS 原生验收。重命名历史串联、历史保留策略设置和跨平台原生验收仍待补齐。
3. **导出（基础功能已实现）**：带递归关联笔记和附件的 Markdown/HTML 目录导出、路径转换、HTML 标题锚点及打印样式；macOS 原生导出、浏览器链接导航、实际 PDF 保存与预览通过。PDF 当前借助浏览器打印，尚无应用内直接生成；嵌入笔记转为链接，公式/Mermaid/高亮、块锚点和高级排版仍待完善。
4. **附件管理（基础功能已实现）**：路径/类型/至少 1 MiB 筛选、按大小排序、引用来源跳转、系统图片/PDF 预览、疑似未引用附件逐项确认并移入回收站。macOS 原生 PDF 预览及清理恢复闭环通过；内置预览与批量清理仍待完善。
5. **搜索与组织（进行中）**：已实现保存搜索（含大小写/排序）、打开正文快照检索与未保存标记、本地链接健康检查；已补齐文字/正则批量替换与标签重命名/合并，支持目录范围、逐篇勾选、差异预览、基线校验和版本历史。标签合并及选择应用完成 macOS 原生验收。
6. **日常体验（待实现）**：设置搜索、统一保存反馈、快速记录、可视化表格、专注模式和无障碍验收。

模板、日记和关系图谱维持用户此前移除的范围。同步、移动端、协作、插件与 AI 尚未纳入本轮实现承诺。上述“已实现”与“原生验收通过”分开记录，具体证据见 [TESTING.md](TESTING.md)。

## 当前状态（2026-09-28）

可运行的 Windows 桌面 MVP 已交付。主界面和编辑器使用 Rust + GPUI；依赖及 Cargo.lock 已锁定。39 项自动测试、严格 Clippy 和 Windows release 构建通过，关键原生文件闭环与恢复流程有运行证据。

此状态对应下方原定完成条件，不表示所有平台、输入法和性能场景均已验收。未验证项目继续保留，不记为通过。用户已授权：后续若遇 `GetCursorPos` 拒绝访问，跳过受影响测试并记录；最新一轮桌面控制正常，没有使用这项豁免替代实测。

## GPUI 判断

已有原生闭环、中文输入、阅读和导航证据，足以继续采用 GPUI 维护这一 MVP。现维护 gpui-base 六个文件的受控补丁，升级需要重跑字素边界、选区和几何回归。生产级编辑体验仍需扩展上述验收。
