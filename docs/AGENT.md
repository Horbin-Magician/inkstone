# Agent 笔记助理

Agent 使用用户配置的模型服务检索、阅读笔记并提出修改。它不会自行写入笔记；只有点击提案的“接受并应用”才会修改内容。

## 开始使用

1. 从右侧栏的 Agent 图标、命令面板“发送当前笔记或选区给 Agent”，或编辑器右键菜单进入。
2. 打开统一设置中的“Agent”页面（也可点击 Agent 侧栏的设置按钮跳转），填写配置名称、服务地址（默认 `https://api.openai.com/v1`）、模型名称和 API Key。默认配置为 OpenAI 的 `gpt-6-astra`，上下文容量 1,050,000 token，输出上限 128,000 token；使用官方服务需填写自己的 API Key。本地免认证服务可留空密钥。官方 OpenAI 地址使用 Responses SSE 流式接口；其他兼容服务使用 Chat Completions SSE 流式接口。
3. 按需调整上下文容量与输出上限，保存配置。输出上限包含推理 token，官方接口使用 `max_output_tokens`，其他兼容接口使用 `max_completion_tokens` 发送。默认值仅用于首次创建或新增配置，已有保存配置不覆盖。可新增多个配置，在输入框下方的模型菜单或设置页“当前配置”菜单中切换。
4. “测试连接与工具”仅发送合成测试请求，不发送笔记内容。Agent 要求模型支持工具调用；未返回有效工具调用时会提示检查配置或更换模型。HTTP 错误显示状态码及可安全展示的错误类型、代码和参数名，不显示服务端原始错误正文；可修改配置后重试。
5. 输入任务后按 Enter 或点击发送按钮，Shift+Enter 换行；空白会话可直接点选建议任务填入输入框。长任务随时点击停止按钮中止。新会话、会话历史（右上角菜单，可切换或删除）、切换模型和应用修改时不能有正在运行的任务。

API Key 按用户选择以明文独立存放于应用数据目录的 `agent-secrets.json`，输入框默认遮挡。模型配置在 `agent-settings.json`；会话与修改记录在 `agent/`，按笔记库路径的哈希隔离。这些文件不进入笔记库或 WebDAV 同步。普通日志不记录认证头与服务错误正文。

默认模型与容量依据 [OpenAI 模型文档](https://developers.openai.com/api/docs/models/gpt-6-astra)，请求适配依据 [Responses 迁移文档](https://developers.openai.com/api/docs/guides/migrate-to-responses)。官方请求使用 `store: false`，仅在当前任务内回传完整输出项和加密推理状态以继续工具调用。

## 上下文与引用

默认范围是当前笔记；存在选区时只向模型提供选区内容。读取的是编辑器已提交正文，可以包含尚未保存的修改，正在组词时不能发送。输入框下方的范围菜单会显示当前笔记名，存在选区时显示“选区 · 笔记名”。可以切换到指定文件夹、逗号分隔的笔记路径或整个笔记库；文件夹与笔记均使用库内相对路径。排除目录在模型设置中配置，对所有范围生效。

全库模式按授权范围构建全文与双链索引，分段读取命中笔记，不一次发送整个库。其他笔记使用磁盘版本。当前笔记模式不扫描整个库。首版不解析 PDF、图片或其他附件，也不支持向量检索、联网搜索、MCP 或命令执行。

来源由应用分配编号。回复下方的来源按钮可以打开笔记并定位；内容版本变化时会提示，打开当前版本而不沿用旧位置。模型回复中的普通文字不会自动获得可执行链接或权限。历史回答及笔记正文不能改变本次工具允许范围。

改变范围后不再重发旧范围的对话上下文；新会话或重新选择会话后的下一轮也从当前授权资料开始。旧消息仍可本地查看。长对话采用摘录压缩，保留用户要求及工具调用配对，较早的工具正文需要时重新读取；预算仍不足时明确停止。

## 问答、写作与整理

- 问答示例：“这几篇笔记对项目风险有哪些不同判断？请引用来源。”
- 写作示例：选中段落，右键选择“Agent 润色”，修改任务描述后发送。
- 整理示例：选择文件夹或全库，“整理有关 Rust 学习的笔记，新建一篇索引笔记并补充双链。”
问答、写作与整理使用同一个输入入口，无需切换模式。Agent 根据任务直接回答或通过工具提出修改；所有修改仍需审阅并接受后才会应用。

Agent 可以列举笔记、全文/文件名/标签检索、分段阅读、大纲、双链与反链查询，以及提出内容、属性和标签修改。替换已有笔记前必须读完整个目标范围。新建笔记需要路径落在所选范围内；只选择当前已有笔记时不能另外创建库中其他路径。

单个工作区一次运行一个任务，每轮任务最多 12 次模型请求、40 次工具调用、100 篇修改。重复调用无进展会停止。达到上限后保留已生成结果，可输入补充要求继续。最新回复下方显示最近一次模型请求返回的 token 用量（输入、缓存、输出、推理与合计，悬停可看精确值；不累计整轮任务）；未返回时显示未知，不估算账单。

## 审阅、保存与恢复

提案显示完整改动的差异预览、路径和原因。过大的差异预览会注明截断。修改既有笔记的独立提案可分别接受或拒绝；本轮包含新建笔记时，所有提案保守合并为一组，避免分开接受后缺失新链接目标。

- 单篇、已打开的笔记：确认正文仍与生成提案时一致后，通过共享编辑器应用；一次撤销可回到修改前，随后遵循原有保存流程。应用不等于已经保存到磁盘。
- 多篇或未打开的笔记：目标不能有未保存编辑、组词或冲突。整批先核对全部基线，取得独占文件操作凭据，再逐文件条件写入并记录历史。不会隐式保存其他笔记。
- 若预览后发生修改，拒绝旧提案，需重新生成；同一提案不能重复应用。
- 某篇写入失败后停止后续操作，逐文件展示已写入、失败和未执行，不自动回滚或重试整批任务。
- 点击停止应用时，完成当前安全写入，再停止后续文件。

提案中的“查看版本历史 / 恢复”复用已有恢复入口。恢复时仍遵循原有冲突检查和恢复副本规则，不覆盖之后的人工编辑。新建文件没有修改前正文，首版不提供批量删除式撤销。

会话支持新建、切换和删除；删除会话不撤销已应用的笔记修改。会话在执行开始、运行期间、结束以及应用前后保存；应用前等待检查点持久化。重启后未完成任务标记为中断，不自动重放请求或写入。切库取消旧运行，旧结果不会进入新库。

## 验证边界

自动回归使用临时笔记库、模拟模型与本地 HTTP 服务，不使用个人笔记或真实 API Key。提供可重复的合成检索测量：

```sh
cargo test --locked -p inkstone-agent
cargo run --locked -p inkstone-agent --example benchmark -- 1000
```

不同供应商的“兼容 API”可能不支持相同的流式事件、工具调用或参数。已实现的是协议适配与本地契约测试，不代表所有供应商已认证。真实服务、Windows 原生操作、macOS 完整点击与读屏验收仍需补充；具体记录见 [验证指南](TESTING.md)。

真实 OpenAI 合成冒烟可运行 `cargo run --locked -p inkstone-agent --example openai_probe`，通过标准输入传入测试密钥并结束输入。它会产生两次计费请求，仅验证合成工具调用、结果回传与最终回复，不读取笔记；请勿将密钥放入命令参数或提交文件。
