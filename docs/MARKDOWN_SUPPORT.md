# Markdown 支持矩阵

本轮目标：CommonMark、GFM、Obsidian 常用扩展；解析和渲染采用 Rust，笔记仍保存原始 Markdown。
“源码”表示可保留和编辑原文，不代表已完成呈现。阅读与实时预览分别验收。

| 功能 | 源码 | 阅读 | 实时预览 | 自动验证与边界 |
| --- | --- | --- | --- | --- |
| 标题、强调、删除线、列表、引用、分隔线 | 原文编辑 | 已有 | 已有文字样式 | 嵌套、转义、换行与定位；未逐条验收规范全集 |
| 链接、双链、高亮、注释 | 原文编辑 | 已有 | 已有 | 统一解析边界与来源映射 |
| 普通与引用式图片 | 原文编辑 | 已接入 | 原生预览 / 活动位置源码 | 引用定义在片段外、标题、相对路径、CRLF、原文复制 |
| 表格 | 原文与命令 | 已接入 | 表格 / 点击源码 | 测量高度、源码编辑与导航、跨块选择、原文复制 |
| Callout、笔记嵌入 | 原文编辑 | 已有 | 复用阅读片段 | 原生控件、任务来源、版本检查 |
| 命名脚注 | 原文编辑 | 编号、导航、编辑 | 上标与文末内容 | 与阅读共用编号、来源隔离 |
| 行内脚注 | 原文编辑 | 已接入 | 上标、文末内容、编辑窗 | 只转换展示，源码与撤销保持原语法 |
| 数学公式 | 原文编辑 | RaTeX SVG | 后台图形 / 活动位置源码 | 必需公式、中文、化学、颜色、基线、错误回退 |
| Mermaid | 原文编辑 | 原生 Rust SVG | 后台图形 / 活动位置源码 | 十一类基础及组合测试、关键标签、窄窗口等比例缩放 |
| HTML | 原文编辑 | 原生格式、上下标、折叠 | 阅读片段 / 活动位置源码 | details 点击、源码复制、HTML 相对链接与图片 |

测试样例在 `tests/fixtures/markdown/`，只在独立测试库使用。不得以用户笔记作为测试数据。

## 验收

- 每项分别验证解析、阅读、实时预览；有效目标语法回退为源码不能标记为完成。
- 位置使用 UTF-8 字节，验证 CRLF、中文、emoji、代码区和转义。
- 模式切换、渲染、缩放不修改正文或历史；编辑复用现有共享正文和撤销。
- 记录自动测试与真实 Windows UI 验证；编译通过不代表视觉验收。
- 对比普通笔记、330 KB 长文和复杂块的同机性能，P95 键入/滚动增长不超过 20%。

## 边界

数学模式的常用 LaTeX，不包括完整文档、任意宏包与 TikZ。原生 Mermaid 可与官方布局不同，不能遗漏结构或文字。HTML 不执行脚本或任意网页样式。PDF、音视频保留附件入口。

Mermaid 0.3.1 原生 SVG 会遗漏时间线 `section` 标签，Inkstone 在解析后的展示图中将分组名放入该分组的首个时间卡片，保留顺序和事件关联，不改动笔记原文。这与 [Mermaid 官方分组说明](https://mermaid.js.org/syntax/timeline.html#grouping-of-time-periods-in-sections-ages) 的横向分组标题布局不同。组合样例见 `tests/fixtures/markdown/mermaid.md`。

## 本轮实现与待验收

- 原生图形使用 RaTeX 0.1.14 与 mermaid-rs-renderer 0.3.1；无浏览器或 JavaScript 运行时。数学字体轮廓随程序嵌入，字体许可见 `licenses/`。
- 图形缓存上限 64 MiB；图形输入上限 64 KiB、单边逻辑尺寸上限 8192px，栅格化前检查内存预算。超过预算保留原文及诊断。
- 编辑组件使用独立 `DisplayObject` 展示投影，支持跨行隐藏、可变高度、字素范围校验、编辑失效和源滚动锚点恢复。图形与表格编辑继续使用源码。
- 2026-10-01 已恢复 Windows 真窗口操作，完成深浅色阅读 / 实时预览、中文公式与图表、表格点击源码、脚注、HTML 折叠和约 854px 窄窗口基础检查。原生启动检查发现并修复投影样式的 UTF-8 边界异常。
- 100%/150%/200% DPI 全矩阵和实际输入延迟仍未验收：本轮启动系统设置未获得可操作窗口。图形缓存测试覆盖 DPI 重栅格化，不能替代完整桌面实测。
- 调试构建的同机无头 GUI CPU 帧基准已建立。普通笔记和约 310 KB 长文接近或优于改前基线；富内容开销增加，尚未达到相对改前源码预览增长不超过 20% 的目标。不得据此宣称性能验收完成。

## 2026-10-01 审计结果

计划尚未完整验收。本轮补齐实时公式基线、图形测量尺寸复用、缩放时复用原始 SVG、引用图片、片段中的引用链接、Mermaid 时间线分组名称和窄窗口宽度适配。组件无高亮器路径现在按可见行压缩样式范围，投影片段复用 UTF-8 边界校正，避免 Windows DirectWrite 原生异常。

自动检查通过 365 项应用 / 核心 / 集成测试及 1,230 项组件测试。组件测试同时修复了旧夹具缺失字段和仍按纯文字脚注选区编写的旧测试。详细检查、性能数字和未完成验收见 `TESTING.md`；不得把已接入等同于所有规范样例、IME / 多视图编辑和多 DPI 视觉组合均已验收。
