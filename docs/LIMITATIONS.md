# 已知限制与验收缺口

1. 原生创建、保存、重开、阅读、搜索、大纲和 Ctrl+Enter 已完成基础检查；Ctrl+点击、补全菜单、长文档、多 DPI 和性能仍未全部验收。17:26 桌面再次锁屏后停止自动输入。
2. 实时预览隐藏标记保留宽度，标题不改变字号；限定为 ATX 标题、简单双星号粗体、单反引号代码和双链。复杂嵌套 / 多反引号 / 表格 / 图片使用源码与阅读视图。
3. 多 DPI、滚动后的微软拼音候选窗、超长文档输入与鼠标跨行选择仍未测完。
4. 读取仅接受 UTF-8；损坏或非 UTF-8 的 Markdown 会报错，可能阻止索引重建。没有自动转码。
5. 搜索和反链使用已保存文件索引；通常在监听事件处理后更新。每次搜索最多展示 200 条，补全最多 40 条。
6. 目录内容变化后目录树可能恢复折叠状态；外部干净文件重载会重置组件历史 / 滚动，尽量恢复选区。编辑器内普通切换保留各标签实体。
7. 回收区有原路径记录，可用文件管理器恢复；尚无专门的图形回收站。恢复草稿写到新笔记，旧恢复记录仍保留。
8. 恢复记录和已提交记录不自动清理。自动保存目标间隔 2 秒；崩溃时未落入恢复区的输入仍可能丢失，慢速 / 失败 IO 或组词期间可能超过一个周期。
9. 极端替换竞争可能使本地版本位于原路径、外部版本位于 `.inkstone-*.external-backup`。应用明确报告冲突并保留两者，不自动回滚。
10. 当前验证的文件系统为 Windows NTFS；依赖同卷替换与硬链接，FAT、网络盘和断电恢复不作保证。macOS/Linux尚未验收。
11. 一万篇小文档首次逻辑索引约 10–12 秒。后台测量不代表窗口启动 / 键入 / 滚动性能；相关指标仍待测。
12. 本轮提供源码与可执行文件，没有安装器、签名、自动更新。没有云同步、移动端、插件兼容、关系图或多人协作。

这些是待办与边界，不代表用户目标已通过验收。
