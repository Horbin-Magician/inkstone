# 已知限制与验收缺口

本次 Obsidian 对齐工作进行中，新增功能与当前剩余项见 [对齐清单](OBSIDIAN_PARITY.md)。以下保留 MVP 的平台、编辑与数据安全验收记录。

1. 原生创建、保存、重开、阅读、搜索、大纲、Ctrl+Enter、补全键盘、反链和长中文已完成基础检查；最终字素 / 重排 / 焦点 / 万条反链滚动条已复查。写失败后强制退出并从界面恢复草稿通过。Ctrl+点击、补全鼠标选择、多 DPI 和完整性能仍未全部验收。
2. 实时预览已接入源坐标文字样式及复杂块投影，非活动图片、表格、Callout、嵌入、公式和图表可呈现，编辑位置展开源码；脚注与常用 HTML 已补齐。2026-10-01 补齐引用图片与片段引用链接、实时公式基线、Mermaid 时间线分组和窄窗口缩放，完成深浅色原生基础检查；续验修复 IME 预编辑时复杂块展开跳变，实际微软拼音、任务单点修改、中文 / 字素删除与撤销通过。完整多 DPI、更多编辑组合和富内容相对性能目标仍未验收完成，详见 MARKDOWN_SUPPORT.md。
3. 330 KB 文档滚动后的微软拼音、鼠标跨行选择与剪切粘贴已有基础实测。当前远程会话比例 200%，显示设置禁止远程调整；100% / 150%、更多软换行边界及搜狗未验证。
4. 读取仅接受 UTF-8；损坏或不可读的 Markdown 单独排除出搜索索引，仍保留文件树入口，状态栏显示异常数量及路径。其他笔记继续加载和刷新，文件修复后监听更新会重新索引。没有自动转码。
5. 搜索和反链使用已保存文件索引；通常在监听事件处理后更新。每次搜索最多展示 200 条，补全最多 40 条。
6. 目录展开状态已加入工作区持久化；外部干净文件重载会重置组件历史 / 滚动，尽量恢复选区。编辑器内普通切换保留各标签实体。
7. 回收区有原路径记录，现有图形回收站可恢复文件和文件夹，并拒绝覆盖已存在的目标。恢复草稿写到新笔记，旧恢复记录仍保留。
8. 失败恢复记录及冲突备份不自动清理；成功历史按 30 天、每库 128 MiB 软上限清理，至少保留每篇笔记最新成功记录，有未解决草稿的笔记保留其历史。自动保存目标间隔 2 秒；崩溃时未落入恢复区的输入仍可能丢失，慢速 / 失败 IO 或组词期间可能超过一个周期。
9. 极端替换竞争可能使本地版本位于原路径、外部版本位于 `.inkstone-*.external-backup`。应用明确报告冲突并保留两者，不自动回滚。
10. 当前验证的文件系统为 Windows NTFS；依赖同卷替换与硬链接，FAT、网络盘和断电恢复不作保证。macOS/Linux尚未验收。
11. 一万篇小文档后台基准首次逻辑索引约 10–12 秒；另一原生样本首次编辑器帧约 2.43 秒。两者样本及缓存条件不同，不可直接比较。真实窗口已有少量混合操作 profiler 样本，完整键入 / 滚动 / 搜索和多轮统计仍待补。
12. 本轮提供源码与可执行文件，没有安装器、签名、自动更新。没有云同步、移动端、插件兼容或多人协作。
13. 维护 gpui-base 0.7.0 的编辑、投影与富文本补丁，并锁定 unicode-segmentation 1.13.3；后续升级须按 EDITOR_PATCH.md 核对补丁和 Unicode / 原生编辑回归。

这些是交付后的验收待办与能力边界。MVP 完成条件的证据见 PROGRESS.md，不代表所有场景已经通过验证。
