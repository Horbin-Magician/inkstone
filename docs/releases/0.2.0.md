# 墨砚 0.2.0

本次更新改进文件管理、Markdown 实时预览与日常操作，并优化编辑和文件索引的重复计算。

## 新增与改进

- 文件树支持拖拽移动笔记和文件夹，以及原地编辑名称。
- 实时预览支持普通代码块呈现、语法高亮和复制操作。
- 优化编辑投影、闭合代码块增量解析、长段落布局和启动恢复，复用正文快照与解析结果。
- 文件移动与索引刷新复用已解析笔记，减少文件树子目录重复复制，并将移动后的索引准备移到后台。
- 调整状态栏信息布局，使用图标展示同步与反向链接状态。
- Windows 应用内嵌多尺寸图标，安装器创建桌面快捷方式，并改善图标显示大小。

## 修复

- 修正实时预览引用样式及列表中引用竖线的缩进。
- 修复缩进公式列表被识别为代码块的问题。
- 统一阅读模式代码块的语言名称处理。
- 修复设置页快捷键区域的滚动行为。

## 下载

- Windows x64：`-setup.exe` 为当前用户安装器，`.zip` 为便携包。
- macOS Apple Silicon：选择 `aarch64-apple-darwin.dmg`。
- macOS Intel：选择 `x86_64-apple-darwin.dmg`。
- `.app.tar.gz` 为 macOS 应用归档；各平台 `.sha256` 提供 SHA-256 校验和。

## 已知限制

这是早期版本，界面固定为中文，Linux 不在支持范围内。
Windows 安装器尚无发行签名，macOS 使用临时签名、尚未公证，系统可能提示未验证发布者。
尚无自动更新，需要手动下载安装。
性能优化不代表完整原生性能验收通过；大文档空闲 CPU、输入延迟、完整读屏和多 DPI 场景仍有待验证。
WebDAV 服务器需支持强 ETag 与条件 PUT；凭据以明文保存在本机应用数据中。
完整能力与限制见仓库的使用指南和项目状态页。
