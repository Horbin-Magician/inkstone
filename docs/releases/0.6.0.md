# 墨砚 0.6.0

本版支持放大查看 Mermaid 图表、逐篇审阅 Agent 的完整修改，以及预览并批量清理笔记库中疑似未引用的图片。

## 编辑与阅读

- 在阅读或实时预览中，将鼠标移到 Mermaid 图表上，点击右上角的放大镜即可查看大图。滚轮缩放，拖动平移，双击恢复适应窗口，按 Esc 返回笔记。图表使用透明背景。
- 在阅读、实时预览和源码视图中，拖动正文两侧的细条可调整文字宽度，双击恢复默认。宽度按笔记库保存，也用于分屏。
- 修复使用 Windows 换行符的笔记在软换行时将行尾字符计入布局的问题。

## 图片清理

- 从命令面板或笔记的“更多选项”打开“清理未使用的图片（先预览）”，可按路径筛选候选图片，核对数量、大小和路径后批量移入回收站。图片可从“文件恢复”找回。
- 扫描同时检查已保存笔记和未保存编辑中的直接引用。若仅在草稿中删除了最后一个链接，需保存并刷新后才能清理该图片。

## Agent、搜索与设置

- 在 Agent 提案中点击“查看完整修改”，可按文件切换并翻页核对差异，再决定是否应用。旧提案也可打开完整审阅。
- 全文搜索按笔记分组，分别显示笔记数与匹配条数，同名笔记会显示所在目录。设置搜索可直接跳到对应控件并短暂高亮。
- 修复快速切换笔记时按回车及输入法组词的处理，也修复了 Agent 读取带 Windows 路径分隔符的嵌套笔记路径的问题。

## 下载与升级

- Windows x64 提供安装器和便携 ZIP。Windows 安装器尚无发行签名。
- Apple Silicon Mac 提供 DMG 和应用归档，应用与 DMG 均经过 Developer ID 签名和 Apple 公证。
- 发布附件包含 SHA-256 校验和。使用 0.3.0 及以上版本时，可在“设置 → 关于与更新”下载新版，再打开安装包完成升级。
