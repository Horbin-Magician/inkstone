# 墨砚 0.5.0

新增 Agent 笔记助理，可以围绕选区、当前笔记或指定范围提问、润色和整理笔记。点击回答中的来源编号即可回到原文，修改提案由你审阅并接受后写入。

## Agent 笔记助理

- 在“设置 → Agent”配置支持工具调用的模型，再从右侧栏打开助理。选中一段文字后，也可通过右键菜单发起润色。
- 支持按正文或文件名检索笔记，沿双链与反链查找相关内容。切换检索范围后，后续请求只使用当前授权范围内的资料。
- 可根据已读片段提出局部替换，也可提议新建笔记、修改属性。回答支持流式显示，可随时停止，完成后可查看本次任务的 token 用量。

## 设置与同步

- 重新组织设置导航，将外观、备份、云同步、文件、快捷键、Agent 和关于页面统一到同一窗口。云同步页集中展示当前状态。
- 同步后，已删除笔记的标签页会关闭，已移动笔记的标签页会跟随新路径。同步冲突副本的文件名长度限制与移动端保持一致。

## 下载与升级

- Windows x64 用户可下载 `-setup.exe` 安装器或便携版 `.zip`。Windows 安装器尚无发行签名。
- macOS Apple Silicon 用户可下载 `.dmg` 安装包或 `.app.tar.gz` 应用归档。应用与 DMG 均经过 Developer ID 签名和 Apple 公证。
- 每个下载文件均附有 SHA-256 校验和。使用 0.3.0 及以上版本时，可在“设置 → 关于与更新”下载新版，再打开安装包完成升级。
