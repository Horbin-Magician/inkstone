# 墨砚 0.4.0

本次更新新增 Markdown 斜杠命令，调整工作区界面，并集中改进编辑、链接导航、文件操作和恢复的可靠性。

## 新增与改进

- 新增斜杠命令，可在编辑器中快速插入 Markdown 块。
- 调整工作区边框、活动标签页轮廓和侧栏控制布局，统一图标尺寸与颜色。
- 优化 Markdown 解析、补全、搜索、文件树、批量编辑、导出和历史记录扫描，减少重复解析与临时数据复制。
- 改进折叠控件、冲突与恢复面板的辅助功能信息，以及按钮、复选框等控件的禁用状态表达。

## 修复

- 修复特殊文件名、转义字符、格式化别名和标题片段在链接补全、重命名、导航及导出中的处理，保留图片尺寸、附件引用和笔记嵌入。
- 跳转标题时使用已打开笔记的最新草稿；链接诊断支持定位到来源位置。
- 修复中文标点附近的强调解析、字体回退的粗体显示、行尾处理、行复制选区和行内代码边缘空格等编辑问题。
- 修复分栏替换时的待提交输入、切换笔记库后的旧导航状态，以及附件选择器和文件菜单操作的目标绑定。
- 改进历史记录归属、备份保留与恢复处理，显示文件选择失败原因，避免凭据替换失败时丢失已保存凭据。
- 修复菜单键盘导航、禁用子菜单焦点、对话框确认、嵌套焦点限制和停靠面板选中项滚动等交互问题。
- 改进更新、备份和同步过程中的中断读取处理，以及发行包内符号链接的完整性校验。

## 下载与升级

- Windows x64：`-setup.exe` 为当前用户安装器，`.zip` 为便携包。
- macOS Apple Silicon：选择 `aarch64-apple-darwin.dmg`；`.app.tar.gz` 为应用归档。
- 各平台 `.sha256` 文件提供 SHA-256 校验和。
- 0.3.0 用户可通过“设置 → 关于与更新”检查并下载新版本，再运行安装包完成升级；更早版本请手动下载安装包。

## 已知限制

这是早期版本，界面固定为中文，Linux 与 macOS Intel 不在支持范围内。
Windows 安装器尚无发行签名，macOS 使用临时签名、尚未公证，系统可能提示未验证发布者；SHA-256 校验和不等同于数字签名。
应用内更新仍需用户运行安装包完成安装。
大文档空闲 CPU、输入延迟、完整读屏和多 DPI 场景仍有待验证。
WebDAV 服务器需支持强 ETag 与条件 PUT；凭据以明文保存在本机应用数据中。
完整能力与限制见仓库的使用指南和项目状态页。
