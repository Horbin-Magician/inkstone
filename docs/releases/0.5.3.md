# 墨砚 0.5.3

本次更新为 Agent 笔记助理加入 DeepSeek 联网搜索与网页阅读，并修复全部标签页下拉菜单的交互。

## Agent 联网检索

- 在“设置 → Agent”配置 DeepSeek 联网 API Key 后，支持工具调用的模型可搜索网页、读取网页正文，并在回答中提供网页来源链接。
- 联网密钥由所有模型配置共用；未单独配置时，仅使用 DeepSeek 官方服务地址的模型会复用其模型密钥。
- 支持分段读取长网页，同一轮会话中的页面缓存可避免重复请求；联网请求支持取消，并对响应大小和请求时间设置限制。
- 搜索词和待读取的 URL 会发送给 DeepSeek；联网接口可能产生独立服务费用，不计入界面的模型 token 用量。配置与使用说明见 [Agent 指南](https://github.com/Horbin-Magician/inkstone/blob/v0.5.3/docs/AGENT.md)。

## 修复

- 修复“全部标签页”下拉菜单的交互，恢复通过菜单切换已打开笔记。

## 下载与升级

- Windows x64 用户可下载 `-setup.exe` 安装器或便携版 `.zip`。Windows 安装器尚无发行签名。
- macOS Apple Silicon 用户可下载 `.dmg` 安装包或 `.app.tar.gz` 应用归档。应用与 DMG 均经过 Developer ID 签名和 Apple 公证。
- 每个下载文件均附有 SHA-256 校验和。使用 0.3.0 及以上版本时，可在“设置 → 关于与更新”下载新版，再打开安装包完成升级。
