# 墨砚 0.4.1

本次更新改进标题栏与侧栏交互，并修复侧栏菜单和 macOS 分隔线显示问题。

## 新增与改进

- 支持将左、右侧栏分隔线向窗口边缘拖动以隐藏对应侧栏。
- 优化 Windows 标题栏，增大窗口控制按钮的宽度与图标尺寸。
- 右侧栏工具按钮根据可用宽度收纳到“更多”菜单，优先保留当前视图入口；加宽后恢复显示。
- 收紧侧栏折叠按钮周围的间距。

## 修复

- 修复右侧栏“更多”菜单无法正常点击的问题。
- 修复 macOS 侧栏标题区域分隔线，并使窗口控制按钮下方的分隔线与完整标题栏对齐。

## 下载与升级

- Windows x64：`-setup.exe` 为当前用户安装器，`.zip` 为便携包。
- macOS Apple Silicon：选择 `aarch64-apple-darwin.dmg`；`.app.tar.gz` 为应用归档。
- 各平台 `.sha256` 文件提供 SHA-256 校验和。
- 0.3.0 及以上版本用户可通过“设置 → 关于与更新”检查并下载新版本，再运行安装包完成升级；更早版本请手动下载安装包。

## 已知限制

这是早期版本，界面固定为中文，Linux 与 macOS Intel 不在支持范围内。
Windows 安装器尚无发行签名，macOS 使用临时签名、尚未公证，系统可能提示未验证发布者；SHA-256 校验和不等同于数字签名。
应用内更新仍需用户运行安装包完成安装。
大文档空闲 CPU、输入延迟、完整读屏和多 DPI 场景仍有待验证。
WebDAV 服务器需支持强 ETag 与条件 PUT；凭据以明文保存在本机应用数据中。
完整能力与限制见仓库的使用指南和项目状态页。
