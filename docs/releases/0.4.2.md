# 墨砚 0.4.2

本次更新增加 macOS 正式签名与 Apple 公证，完善文件管理、图片预览及历史恢复体验。

## 新增与改进

- macOS Apple Silicon 应用及 DMG 使用 Developer ID 签名和 Apple 公证，装订公证票据并通过 Gatekeeper 验证后发布。
- 文件树支持显示、打开和管理各类文件；附件存储位置支持快速选择文件夹。
- 图片可在应用标签页中预览，支持缩放按钮和以光标位置为中心的滚轮缩放。
- 合并右侧栏的反向链接与出站链接视图，简化侧栏布局。
- 重新设计新建标签页、回收站、恢复中心和笔记历史界面，提供来源切换、搜索、分栏预览和持续可见的恢复操作。

## 修复

- 修复粘贴 TIFF 图片时的格式处理，转换为 PNG 保存。
- 修复附件文件夹菜单的范围与滚动问题，以及图片缩放工具栏的稳定性。
- 隔离回收站文件和恢复元数据，避免相互干扰。
- 改进恢复界面的标签选择与清空搜索行为。

## 下载与升级

- Windows x64：`-setup.exe` 为当前用户安装器，`.zip` 为便携包。
- macOS Apple Silicon：选择 `aarch64-apple-darwin.dmg`；`.app.tar.gz` 为应用归档。
- 各平台 `.sha256` 文件提供 SHA-256 校验和。
- 0.3.0 及以上版本用户可通过“设置 → 关于与更新”检查并下载新版本，再运行安装包完成升级；更早版本请手动下载安装包。

## 已知限制

这是早期版本，界面固定为中文，Linux 与 macOS Intel 不在支持范围内。
Windows 安装器尚无发行签名，系统可能提示未验证发布者；SHA-256 校验和不等同于数字签名。
应用内更新仍需用户运行安装包完成安装。
大文档空闲 CPU、输入延迟、完整读屏和多 DPI 场景仍有待验证。
WebDAV 服务器需支持强 ETag 与条件 PUT；凭据以明文保存在本机应用数据中。
完整能力与限制见仓库的使用指南和项目状态页。
