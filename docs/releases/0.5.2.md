# 墨砚 0.5.2

本次更新新增笔记标题自动编号，完善编辑器右键菜单与数学块编辑，并改进自动换行和标签栏显示。

## 编辑与阅读

- 支持按笔记开启标题自动编号，在实时预览、阅读视图和大纲中显示层级编号，无需修改 Markdown 原文；编号设置会保存，并在分屏与文件重命名后保持同步。
- 将编辑器右键菜单按标题、列表、行内格式和块插入分组，提供标准编辑操作，并在表格内显示相应的表格工具。
- 支持数学块和分隔线编辑，新增数学块斜杠补全；菜单操作作用于当前聚焦的编辑面板，并支持一次撤销。

## 修复与界面调整

- 根据实际字体排版宽度校验自动换行，并为行末字符预留空间，减少文字超出编辑区域的问题。
- 修复构建编辑器右键菜单时的输入状态借用冲突。
- 调整笔记标签页的间距、边框和选中高亮位置，统一状态栏图标亮度。

## 下载与升级

- Windows x64 用户可下载 `-setup.exe` 安装器或便携版 `.zip`。Windows 安装器尚无发行签名。
- macOS Apple Silicon 用户可下载 `.dmg` 安装包或 `.app.tar.gz` 应用归档。应用与 DMG 均经过 Developer ID 签名和 Apple 公证。
- 每个下载文件均附有 SHA-256 校验和。使用 0.3.0 及以上版本时，可在“设置 → 关于与更新”下载新版，再打开安装包完成升级。
