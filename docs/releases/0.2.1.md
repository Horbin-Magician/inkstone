# 墨砚 0.2.1

本次更新新增系统文件拖放支持，改进文件树操作，并修复实时预览和设置页的显示问题。

## 新增与改进

- 将系统文件拖到左侧目录，可复制导入到指定文件夹或笔记库根目录；同名文件自动编号，导入结果逐文件报告。
- 将 Markdown 文件拖到阅读区域，可直接打开原文件：库内文件在当前窗口打开，库外文件使用独立窗口，并保留保存冲突检查和草稿机制。
- 将文件树中的笔记拖到编辑区域，可在新标签页打开；点击文件夹名称即可展开或折叠。
- Markdown 粗体文本使用主题强调色显示。
- 精简设置页文案，将详细解释移入提示框。

## 修复

- 修复编辑其他内容时，实时预览中的提示块、表格和代码块短暂退回源码的问题。
- 稳定脚注在无关编辑期间的预览布局，保留未变内容的视图和尺寸。
- 修复设置页滚动条未固定在视口边缘的问题。
- 修复关闭笔记最后一个标签页后，文件树仍保留该笔记选中状态的问题。
- 关闭主窗口时，仍在编辑的独立文件窗口继续保持打开。

## 下载

- Windows x64：`-setup.exe` 为当前用户安装器，`.zip` 为便携包。
- macOS Apple Silicon：选择 `aarch64-apple-darwin.dmg`。
- `.app.tar.gz` 为 macOS 应用归档；各平台 `.sha256` 提供 SHA-256 校验和。

## 已知限制

这是早期版本，界面固定为中文，Linux 不在支持范围内。
Windows 安装器尚无发行签名，macOS 使用临时签名、尚未公证，系统可能提示未验证发布者。
尚无自动更新，需要手动下载安装。
系统拖放和多窗口行为已有自动回归覆盖，尚未完成原生系统拖放与 macOS 实机验收。
大文档空闲 CPU、输入延迟、完整读屏和多 DPI 场景仍有待验证。
WebDAV 服务器需支持强 ETag 与条件 PUT；凭据以明文保存在本机应用数据中。
完整能力与限制见仓库的使用指南和项目状态页。
