# 墨砚 0.5.1

本次更新调整浅色与深色界面，改进 Agent 会话恢复和流式响应的稳定性，并修复文件操作与侧栏布局问题。

## 界面与交互

- 统一浅色、深色主题及编辑区的文字、链接和标记样式，调整中性色，移除灰色区域的蓝色偏色。
- 优化欢迎页、新标签页、左右侧栏、设置窗口和命令面板，重新整理“关于与更新”页面的信息与操作。
- 改进 Agent 修改提案和工具日志的键盘导航与文字尺寸，修复工具日志按钮的悬停样式。
- 调整文件树内新建、重命名输入框的外观；修复右侧栏收窄时工具栏按钮越界的问题。

## Agent 稳定性

- 恢复会话时保留当前授权范围内的对话上下文，切换范围后继续隔离此前范围的内容。
- 按不同模型接口的实际请求内容计算上下文预算并压缩历史，改进长对话的请求处理。
- 复用网络连接，为长时间无响应的流设置等待上限，改善事件积压时的响应和停止操作。
- 兼容仅包含用量统计的流式尾包，修复指定笔记范围内新建笔记的基线判断。

## 编辑与文件操作

- 减少编辑模式下不必要的阅读视图构建、未变化内容的刷新，以及实时预览中屏幕外组件的复制。
- 统一搜索与批量替换的正则表达式限制，减少设置筛选框不必要的重绘。
- 修复文件刷新时空白标签页的处理；删除文件夹时，仅由受影响文档的未保存状态阻止删除，避免无关草稿导致首次删除无效。
- 对无法编码的历史路径返回明确错误，避免程序崩溃。

## 下载与升级

- Windows x64 用户可下载 `-setup.exe` 安装器或便携版 `.zip`。Windows 安装器尚无发行签名。
- macOS Apple Silicon 用户可下载 `.dmg` 安装包或 `.app.tar.gz` 应用归档。应用与 DMG 均经过 Developer ID 签名和 Apple 公证。
- 每个下载文件均附有 SHA-256 校验和。使用 0.3.0 及以上版本时，可在“设置 → 关于与更新”下载新版，再打开安装包完成升级。
