# 墨砚 0.3.0

本次更新新增应用内更新检查与安装包下载，改进安装体验，并修复实时编辑中的 HTML 显示问题。

## 新增与改进

- 在“设置 → 关于与更新”检查正式版本、查看更新说明、下载安装包，支持取消和重试；macOS 应用菜单也提供“检查更新…”。
- 下载完成及打开安装包前验证 SHA-256 校验和，打开后由用户完成安装；不会自动退出或替换正在运行的应用。
- Windows 安装器采用统一品牌页眉与中英文引导，支持 DPI 缩放，安装完成后可直接启动墨砚。
- macOS DMG 新增拖入 Applications 的安装指引与 Retina 背景，简化安装窗口内容。

## 修复

- 实时编辑保留无法识别的 HTML 和自定义标签原文，避免标签消失或在无关编辑时闪烁。

## 下载

- Windows x64：`-setup.exe` 为当前用户安装器，`.zip` 为便携包。
- macOS Apple Silicon：选择 `aarch64-apple-darwin.dmg`；不再提供 macOS Intel 构建。
- `.app.tar.gz` 为 macOS 应用归档；各平台 `.sha256` 提供 SHA-256 校验和。
- 从 0.2.1 及更早版本升级，请手动下载安装本版本；安装后可使用应用内更新检查。

## 已知限制

这是早期版本，界面固定为中文，Linux 不在支持范围内。
Windows 安装器尚无发行签名，macOS 使用临时签名、尚未公证，系统可能提示未验证发布者；SHA-256 校验和不等同于数字签名。
应用内更新仍需用户运行安装包完成安装。
大文档空闲 CPU、输入延迟、完整读屏和多 DPI 场景仍有待验证。
WebDAV 服务器需支持强 ETag 与条件 PUT；凭据以明文保存在本机应用数据中。
完整能力与限制见仓库的使用指南和项目状态页。
