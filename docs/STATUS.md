## 当前能力边界与验收缺口

- **平台与输入**：Windows 与 macOS 已有部分原生验收证据；两平台更多输入法、完整快捷键/读屏路径，以及 100%/150%/200% DPI 全矩阵仍待验证。Linux 不在适配与验收范围内。
- **编辑性能（已跳过）**：长文与富内容已有无头基准，完整原生输入延迟、滚动、搜索、启动、内存和空闲 CPU 统计未完成，本轮不再补测；富内容相对原源码预览的性能目标未验收，不记为通过。详见 [Markdown 支持矩阵](MARKDOWN_SUPPORT.md)。
- **文件与搜索**：仅接受 UTF-8，不自动转码；不可读笔记保留文件树入口并报告异常。搜索和反链可使用打开正文快照，磁盘索引由监听更新；全文搜索最多展示 200 条，补全最多 40 条。
- **历史与恢复**：已关闭正文定时自动保存，默认使用 Cmd+S（macOS）或 Ctrl+S（其他平台）手动保存；关闭及显式文件操作前仍保留保存保护，自动云同步和定时备份等待用户保存。后台独立草稿保护已接入，支持比较、恢复副本和确认放弃；尚未持久化的输入仍可能丢失，macOS 强退重启及恢复副本原生验收已通过，其他平台待验收。成功历史的期限和容量可配置，容量为软上限；失败草稿及冲突备份不自动清理。应用内单篇及目录重命名前后历史已串联，已支持可确认身份时的移动中断协调；外部重命名和身份不明时的处理入口仍待完成；冲突没有自动三方合并。
- **存储可靠性**：已有 Windows 和 macOS 保存、恢复的部分实测；网络盘、FAT、磁盘满和物理断电等场景没有完整保证。外部干净文件重载会重置组件历史/滚动并尽量恢复选区；极端替换竞争保留冲突版本并报告错误。
- **云同步**：设置页支持 WebDAV 配置、连接测试与手动同步，涵盖笔记/附件、修改、重命名和删除；双端冲突保留副本，删除与修改冲突保留修改。密码以明文保存在本机应用数据中，按服务器、用户名和笔记库分开，不写入笔记库；打开后自动填回。已支持自动同步与可配置的周期远端检查。隐藏文件、空目录、设置及历史不参与同步。服务器需支持强 ETag 与条件 PUT，使用墨砚专用清单和内容对象，不能直接同步既有远端普通文件夹。已提供显式云端旧对象清理预览与确认执行；真实服务商、Windows 和原生界面验收待补。
- **分发与依赖**：macOS 支持本机临时签名打包，尚无正式发行签名、公证、安装器或自动更新。维护两个 GPUI 依赖的本地补丁，升级按 [补丁说明](EDITOR_PATCH.md) 回归。
