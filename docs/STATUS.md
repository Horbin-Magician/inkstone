## 产品完善路线


按可独立验证的改动检查、提交，不混入用户笔记。

1. **编辑性能与输入稳定性（进行中）**：普通段落增量解析已实现；release 无头基准 310 KB 长段落键入处理 P95 10.6 ms，非原生显示延迟。长文换行/文本修改、release 原生基准、跨平台输入法及多 DPI 验收仍待完成。
2. **版本历史与冲突处理（主要功能已实现）**：已实现按笔记的历史时间线、保存前/记录正文、差异预览和恢复副本；外部冲突比较、保留本地/采用磁盘、处理前草稿备份与并发变化保护；整库手动/每日/每周备份、SHA-256 校验及恢复到新目录。历史恢复、冲突比较、整库备份恢复已完成 macOS 原生验收。已补齐历史保留期限与容量设置；单篇及目录重命名历史串联已实现，已补齐可确认文件身份时的进程中断协调，跨平台原生验收仍待补齐。
3. **导出（基础功能已实现）**：带递归关联笔记和附件的 Markdown/HTML 目录导出、路径转换、HTML 标题锚点及打印样式；macOS 原生导出、浏览器链接导航、实际 PDF 保存与预览通过。PDF 当前借助浏览器打印，尚无应用内直接生成；已补齐本地 SVG 公式/Mermaid、高亮和块锚点，并完成浏览器视觉与跳转验收。嵌入笔记转为链接，高级分页排版仍待完善。
4. **附件管理（基础功能已实现）**：路径/类型/至少 1 MiB 筛选、按大小排序、引用来源跳转、系统图片/PDF 预览、疑似未引用附件逐项确认并移入回收站。macOS 原生 PDF 预览及清理恢复闭环通过；内置预览与批量清理仍待完善。
5. **搜索与组织（进行中）**：已实现保存搜索（含大小写/排序）、打开正文快照检索与未保存标记、本地链接健康检查；已补齐文字/正则批量替换与标签重命名/合并，支持目录范围、逐篇勾选、差异预览、基线校验和版本历史。标签合并及选择应用完成 macOS 原生验收。
6. **日常体验（进行中）**：已实现跨分类设置搜索（名称与关键词）、当前笔记实时保存反馈、可恢复布局的专注模式；设置关键词定位与专注切换通过 macOS 原生验收。已补齐应用内快速记录（时间命名、位置规则、直接编辑）；已补齐表格单元格编辑、末行末列增删与列对齐（500 单元格上限），快速记录及表格编辑完成 macOS 原生闭环。命令项已改为有名称的按钮，补齐部分设置控件标签，通过 macOS 可访问树读取与操作验收；完整读屏、全键盘路径及其他平台仍待专项验收。

模板、日记和关系图谱维持用户此前移除的范围。WebDAV 手动双向同步已实现；移动端、协作、插件与 AI 尚未纳入本轮实现承诺。上述“已实现”与“原生验收通过”分开记录，具体证据见 [历史验收记录](history/TESTING.md)。

## 当前能力边界与验收缺口

- **平台与输入**：Windows 与 macOS 已有部分原生验收证据；Linux 桌面、更多输入法、完整快捷键/读屏路径，以及 100%/150%/200% DPI 全矩阵仍待验证。核心 Linux CI 配置不等于 Linux 桌面验收。
- **编辑性能**：长文与富内容已有无头基准，完整原生输入延迟、滚动、搜索、启动、内存和空闲 CPU 统计仍待补；富内容相对原源码预览的性能目标尚未完成。详见 [Markdown 支持矩阵](MARKDOWN_SUPPORT.md)。
- **文件与搜索**：仅接受 UTF-8，不自动转码；不可读笔记保留文件树入口并报告异常。搜索和反链可使用打开正文快照，磁盘索引由监听更新；全文搜索最多展示 200 条，补全最多 40 条。
- **历史与恢复**：已关闭正文定时自动保存，默认使用 Cmd+S（macOS）或 Ctrl+S（其他平台）手动保存；关闭及显式文件操作前仍保留保存保护，自动云同步和定时备份等待用户保存。后台独立草稿保护已接入，支持比较、恢复副本和确认放弃；尚未持久化的输入仍可能丢失，macOS 强退重启及恢复副本原生验收已通过，其他平台待验收。成功历史的期限和容量可配置，容量为软上限；失败草稿及冲突备份不自动清理。应用内单篇及目录重命名前后历史已串联，已支持可确认身份时的移动中断协调；外部重命名和身份不明时的处理入口仍待完成；冲突没有自动三方合并。
- **存储可靠性**：已有 Windows 和 macOS 保存、恢复的部分实测；网络盘、FAT、磁盘满和物理断电等场景没有完整保证。外部干净文件重载会重置组件历史/滚动并尽量恢复选区；极端替换竞争保留冲突版本并报告错误。
- **云同步**：设置页支持 WebDAV 配置、连接测试与手动同步，涵盖笔记/附件、修改、重命名和删除；双端冲突保留副本，删除与修改冲突保留修改。密码以明文保存在本机应用数据中，按服务器、用户名和笔记库分开，不写入笔记库；打开后自动填回。已支持自动同步与可配置的周期远端检查。隐藏文件、空目录、设置及历史不参与同步。服务器需支持强 ETag 与条件 PUT，使用墨砚专用清单和内容对象，不能直接同步既有远端普通文件夹。尚未提供云端垃圾回收；真实服务商、Windows/Linux 和原生界面验收待补。
- **分发与依赖**：macOS 支持本机临时签名打包，尚无正式发行签名、公证、安装器或自动更新。维护两个 GPUI 依赖的本地补丁，升级按 [补丁说明](EDITOR_PATCH.md) 回归。
