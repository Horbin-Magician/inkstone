> 历史记录：反映各条目当时的实现与验收情况，不代表当前支持范围。当前进度和限制见 [项目状态](../STATUS.md)，检查方法见 [验证指南](../TESTING.md)。

参考：本机 Obsidian 1.13.7，2026-09-28。采用现有 Rust + GPUI 桌面架构。
排除社区插件兼容、插件市场、账户、同步、发布和商业服务。内置的文件、编辑、导航与本地知识管理仍在范围内。

## 第一批实现

已按本机界面重做合并标题栏、文件工具栏、标签页、面包屑、大纲/反链/出链/标签/属性栏和底部状态栏。使用本地矢量图标；源码与阅读界面移除原有调试说明。提供深浅主题、字号、行号、正文栏宽、左右侧栏折叠与拖动尺寸。

已接入：文件右键菜单、空文件夹、文件/文件夹移动与可恢复删除、回收站、标签拖动/固定/重开、导航历史、书签、会话恢复、可搜索命令与键盘快速切换。快捷键按参考应用调整为 Ctrl+O 快速切换、Ctrl+P 命令面板、Ctrl+Shift+O 打开库。

索引新增标准链接反链、基础 YAML 标签与别名、过滤搜索及正则。重命名文件更新双链和标准 Markdown 目标，每篇文件独立验证基线并保存恢复记录；部分失败会显示错误。属性编辑保留正文与未编辑的 YAML 字段。支持日期日记、以任一笔记为模板插入、附件导入/拖放/图片粘贴和重名自动编号。

工作区配置写在库内 `.inkstone-workspace.json`，保留上次配置备份；笔记正文仍是普通 Markdown 文件。

## 第二批实现：标签生命周期与双视图分屏

- 关闭后台标签保留当前笔记与编辑焦点；未保存标签先保存，成功后关闭。冲突或写失败时保留标签。关闭窗口等待正文与最新工作区状态写入。
- Ctrl+T / 标签栏加号打开空白标签，Ctrl+N 直接创建自动编号的未命名笔记；主编辑区打开文件会复用空白标签。
- 左右、上下双视图分屏，可拖动分隔线。两侧可显示同一篇或不同笔记，各自保留选区、滚动和阅读/编辑模式。
- 同一笔记的两个视图通过一个正文保存者和撤销历史同步；双视图中输入法预编辑不会写入另一侧或磁盘。外部修改与预编辑同时发生时进入冲突处理。
- 会话恢复覆盖分屏方向、两侧文件、阅读/源码模式、选区和滚动偏移。恢复区枚举现在容忍保存过程中记录被重命名的竞争。
- 原生已验证左右分屏输入、共享 Ctrl+Z / Ctrl+Y、独立阅读模式，以及命令面板的上下分屏。该批次不代表完整的任意多层标签组系统已经实现。

## 第三批实现：阅读交互、嵌入与块引用（2026-09-29）

- 实时文字样式改用 Markdown 语法树，覆盖粗体、斜体、删除线、高亮、普通链接、双链别名与多反引号代码；处理转义和代码区边界。
- 阅读任务框可勾选；Ctrl+L 可创建/切换当前行或选中多行的任务状态。正文仍保留原始 Markdown 与换行格式，阅读模式的当前文档撤销/重做接到原编辑历史。
- 支持块标识 `^block-id`、`[[笔记#^block-id]]` 与标题范围定位；大纲和锚点跳转可保持阅读模式。
- 阅读模式展开整篇笔记、标题章节和块的 `![[嵌入]]`；保留每段文本的来源，因此内部相对链接与任务勾选作用于原文件。
- 未打开的嵌入来源通过安全保存更新并检查完整基线，提交后立即更新索引；关闭窗口会等待这类写入。它们尚未加入跨文件撤销栈。
- 支持图片嵌入尺寸 `|宽度` / `|宽度x高度`，以及引用式 Markdown 链接的导航和反链。PDF/音视频暂显示附件入口，没有内嵌阅读器。
- 从本机 1.13.7 的内置 `app.css` 核对正文 16px、1.5 行高、700px 行宽，以及 H1–H6 的 1.618/1.462/1.318/1.188/1.076/1 倍字号；阅读正文、标题与表格接入字号设置。
- 嵌入有循环检测，最多展开 8 层、累计 2 MB 被嵌入原文；达到限制显示说明和原笔记入口，根文档不截断。

原生已验证本地/嵌入任务各自写入正确文件，以及 SVG 尺寸。随后桌面控制返回 `GetCursorPos` 访问被拒绝；最新的阅读撤销、阅读高亮、字体校准和链接实际点击仍需复验。自动交互测试覆盖链接来源、引用块点击、任务撤销、陈旧预览拒绝写入和块定位。

## 第四批实现：紧凑实时预览与标题布局

- 隐藏语法标记使用显示层零宽跨度，原文与撤销记录不变；标题前缀、粗体/斜体、链接目标和别名前缀不再留下横向空位。光标进入对应范围或搜索命中语法时重新显示。
- 编辑会平移未受影响的显示跨度，触及编辑区域的跨度失效；重新解析完成前保留其他区域的样式。拒绝拆分字素或跨换行的隐藏范围。
- 分级标题采用本机样式比例，同时更新软换行、行高、可见区域、光标、选区、输入法候选框与滚动映射；字号变大不是仅在绘制时放大。
- 窄窗口中，隐藏前缀不会形成空白视觉行；窗口重排后保留可见光标。复制仍返回原始 Markdown。
- 自动测试覆盖零宽几何、鼠标命中、原文复制、搜索展开、输入法提交、区域指示符字素、标题行高/上下移动/IME 定位及长标题缩放。原生桌面控制仍返回访问被拒绝，未把这些自动测试计为真实桌面验收。

## 第五批实现：列表与引用的键盘编辑

- Enter 续写无序列表、有序列表、嵌套引用和任务；新任务恢复未勾选状态，有序条目增加编号，保留 CRLF。
- 空条目按层级退出，列表内容起点 Backspace 删除前缀或退一级；Tab / Shift+Tab 调整当前条目或选中列表行的缩进。
- 源码和实时预览共用行为。代码块、前置属性、HTML 与分隔线保持普通输入；Shift+Enter 保留普通换行，补全菜单和输入法预编辑优先处理。
- 每次结构编辑作为独立撤销事务，恢复编辑前后选区。自动测试通过按键分发检查续写、缩进、空项退出、前缀退格和撤销/重做。
- 暂未自动重排后续兄弟条目的编号，未实现整棵列表子树的缩进/拖动。真实桌面输入验证仍待访问恢复。

## 第六批实现：文件夹移动与引用更新

- 文件夹移动按移动前索引一次性计算引用变化：库外层指向移入文件的双链、Markdown 链接、引用式链接，以及移动笔记向外的相对链接一起更新。
- 图片等本地附件参与路径更新，保留双链别名/尺寸、标题与块锚点、Markdown 标题文本；代码区、外部 URL 和文档内锚点保留。
- 每个引用文件使用原正文基线安全保存。部分写入失败会列出对应路径，不把整个操作报告为全部成功。
- 路径操作期间暂停正文保存和索引重载，退出/切库等待操作完成；附件导入、创建文件夹和回收站恢复也纳入在途写入计数。
- 已打开笔记、书签、固定标签、展开目录、导航与关闭历史更新路径。若操作期间输入了新内容，保留编辑并标记冲突。
- 自动测试覆盖磁盘、打开视图、会话路径、附件引用与并发输入保护；完整原生界面验收仍待恢复。

## 第七批实现：编辑区折叠

- Markdown 结构生成标题章节、嵌套列表、引用、代码块与前置属性的折叠范围；折叠到文档末尾也保留可见光标。
- 左侧折叠按钮与标题实际行高对齐；命令面板提供当前区域切换、全部折叠和全部展开。
- 搜索跳转和显式源码定位展开目标所在区域；复制保留完整源文，折叠不写入正文或撤销栈。
- 会话保存每个视图的折叠状态，双视图各自恢复。编辑后平移未触及的折叠范围，解析结果更新范围终点。
- 自动交互验证按钮点击、标题高度、隐藏目标搜索/跳转、复制、编辑后的范围平移，以及独立视图状态恢复。
- 当前折叠作用于源码/实时预览编辑区；阅读视图内折叠、折叠尾部省略标记及更多原生交互仍待补齐。

## 第八批实现：工作区快捷键设置

- 设置页新增“快捷键”分类，可按命令名搜索、录入多个组合键、清除绑定和恢复默认。
- 按笔记库保存覆盖配置并立即生效，命令面板显示当前绑定；清除默认绑定时拦截旧静态绑定，避免重复触发。
- 录入期间只记录按键，不执行原命令；Esc 取消。冲突提示具体命令，恢复默认也检查冲突。
- 普通字符和编辑器基础选择/剪贴板/撤销/查找/定义跳转组合暂不允许分配给工作区命令，避免录入覆盖正文输入。这些编辑器动作的自定义及多段快捷键仍待扩展。
- 自动测试覆盖按键实际触发、禁用旧绑定、录入隔离、冲突、取消及配置序列化。设置页原生外观验收仍待桌面访问恢复。

## 第九批实现：文件管理器排序

- 排序按钮改为菜单，提供名称正/倒序、修改时间新/旧优先、创建时间新/旧优先六种模式，并显示当前选项。
- 名称比较忽略大小写并识别连续数字，避免“笔记10”排在“笔记2”前；超长编号不转换成固定宽度整数。
- 各目录内始终保持文件夹优先，修复原来整体反转把文件夹排在末尾的问题。时间模式下文件夹按名称排列；时间缺失的文件置后、同时间按名称排列。
- 时间信息在后台索引读取，文件正文不变时也刷新元数据；修改时间变化触发重新排序。重建树保留选中文件，排序选项随库恢复。
- 自动测试覆盖比较规则、元数据更新、树状态及持久化；系统语言相关的文件名排序细节和原生菜单外观尚未逐项对照。

## 第十批实现：复制笔记

- 文件右键菜单与命令面板新增“复制当前笔记”，可在快捷键设置中绑定。
- 复制当前已提交的编辑器内容到同目录，保留 Markdown、换行、Unicode 和相对链接；打开副本，原标签路径、正文基线与未保存编辑保持不变。
- 副本名称自动编号，避开磁盘条目和已打开未保存笔记；最终创建继续执行不覆盖检查，应对并发命名竞争。
- 输入法组词期间不复制；复制写入纳入退出和切库等待。既有“另存为副本”仍用于冲突恢复。
- 自动测试覆盖点号文件名、同名避让、越界路径拒绝、最新编辑快照落盘以及原标签保留。原生菜单验收仍待恢复。

## 第十一批实现：全库与局部关系图

- 左侧工具按钮及命令面板可打开原生关系图；局部图按当前笔记与邻接深度显示，支持 1–5 层。
- 图中使用现有解析器解析双链和 Markdown 引用，排除代码区与无效目标；可筛选路径/#标签、显示孤立笔记和未创建笔记。附件暂不作为节点，避免把附件误当成未创建笔记。
- 布局在后台计算，使用邻近网格聚合排斥力；绘制不截断节点数量。过期计算结果不会覆盖新筛选；更新保留仍存在节点的位置和当前视口。
- 支持鼠标滚轮以鼠标位置为中心缩放、拖动空白平移、拖动节点、适应视口与点击打开/创建笔记。Ctrl+W 返回笔记，不会关闭被图谱遮住的笔记标签。
- 自动测试覆盖解析、深度、孤立/未创建节点筛选、实际鼠标点击/拖动、缩放不漂移、筛选竞争，以及工作区节点导航和创建。
- 目前关系图显示在中央工作区，独立图谱标签/分屏、标签/附件节点、动态布局动画、原生外观和大库性能验收仍待完成；设置持久化、颜色分组和力参数已在后续批次补齐。

## 第十三批实现：关系图颜色分组与查询

- 图谱筛选复用全文搜索解析器，支持 `path:`、`file:`、`tag:`、排除条件、OR、引号短语和正则；普通条件匹配路径与正文，保留单个 `#标签` 的简写。
- 控制面板可创建、编辑、删除颜色分组，并调整规则优先级；节点采用第一条匹配规则的颜色，鼠标高亮保留强调色。
- 颜色使用六位十六进制输入并显示色块；无效颜色保留上次有效值，无效查询显示错误。分组条件、顺序和颜色随全库/局部设置分别保存。
- 自动测试覆盖查询兼容、规则优先级、错误条件、颜色输入事件到节点模型，以及分组配置落盘。原生拖动/外观尚未验收；分组排序目前使用上下按钮。

## 第十四批实现：关系图布局参数

- 控制面板新增向心力、排斥力、连接强度和连接距离滑块，参数参与后台布局计算并随图谱设置保存。

- 普通索引/筛选更新保留手动拖动的位置；参数变化和“重新计算布局”明确替换节点布局，并用计算版本避免后续普通刷新覆盖调整。
- 自动测试验证连接距离改变实际节点间距、异常浮点数/越界参数仍得到有限坐标、滑块释放和延迟计算，以及设置落盘。动态动画和真实鼠标拖动体验仍待补齐/验证。
