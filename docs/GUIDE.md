# 使用指南

启动和构建见 [项目首页](../README.md)，当前范围和限制见 [项目状态](STATUS.md)。

## 基础功能


- 文件夹笔记库、最近库、可展开目录树、创建（含子目录）、重命名、可恢复删除。
- 独立编辑状态的标签页、未保存标记、自动保存（2 秒）与手动保存；双视图分屏共享正文及撤销，光标和阅读模式独立。
- GPUI 原生源码编辑、实时与阅读预览；无 WebView 或 JavaScript 运行时。
- 阅读视图接入组件 Markdown 渲染器：标题、列表、任务列表、引用、代码块、链接、表格、本地图片；基础显示已实测，多窗口尺寸回归待补。
- 文件名搜索、全文搜索（最多显示 200 个匹配）、文档内查找、大纲跳转、命令面板。
- 双链补全、Ctrl+Enter / Ctrl+点击定义跳转、阅读链接及出站双链点击、创建缺失目标、反向链接。
- Windows 原生文件监听；后台索引 / 解析 / 文件操作，异步结果校验。
- 保存前恢复记录、同目录安全替换、外部冲突阻止、另存副本、写失败后保留内存内容与错误。

## 双链规则

- `[[笔记]]`：优先同目录；否则按全库同名匹配，唯一时跳转，多个时显示歧义并要求选择。
- `[[目录/笔记]]` 或 `[[/目录/笔记]]`：相对库根目录。
- `[[../笔记]]`：相对当前文件目录，不能越出库。
- 支持 `[[笔记|显示名称]]` 和 `[[笔记#标题]]`。
- 重命名文件会更新能解析到该文件的双链与标准 Markdown 链接；保留显示标签、标题片段和其他原文。每个文件保存前检查冲突，部分失败会明确提示。文件夹移动同样支持更新引用路径，并遵循内部链接更新设置。
- 带点的名称（如 `[[会议.2026]]`）对应 `会议.2026.md`。
- 普通 `[文本](路径.md)` 相对当前文件目录解析，支持中文 URL 编码；目标不存在时提示错误，不自动建笔记。

## 数据与恢复

搜索侧栏可保存当前查询及大小写、排序选项，并从“已保存”菜单重用；载入后可“取消保存”。全文搜索与反向链接使用打开笔记的正文快照，未保存结果有标记，磁盘索引保持独立；正文变化在工作区轮询时刷新，输入法尚在组词的临时内容不参与搜索。

命令“检查本地链接健康”集中列出缺失目标、重名歧义和失效的标题/块引用，可打开来源笔记修正后重新扫描；不访问或检查远程网址。

命令面板支持批量文字/正则替换，以及正文和 YAML 标签的重命名/合并。可限定目录、预览差异并逐篇选择；标签整理忽略代码，可选包含子标签。应用前须先处理未保存编辑与冲突，并核对全部选中文件的磁盘基线；修改前内容保留在版本历史。执行中发生的失败逐项报告，可能部分成功；带 YAML 锚点的标签属性会跳过并说明原因。

命令面板的“附件管理：引用、预览与清理”提供路径搜索、类型筛选、至少 1 MiB 筛选、按大小排序及引用来源跳转。图片/PDF 等附件使用系统默认应用预览。疑似未引用附件可逐项确认移入回收站，再从“查看回收站”恢复；清理前会重新扫描笔记和打开正文，笔记不可读时禁用清理。这不是无用文件判定：脚本、其他附件内容及库外引用不在扫描范围内。

笔记菜单和命令面板支持“导出 Markdown 与关联笔记、附件”与“导出 HTML（浏览器打印 / PDF）”。导出使用当前打开正文的快照，递归收集可解析的关联笔记与附件，重写为可携带的相对路径，只创建库外新目录。HTML 支持基础排版、表格、任务列表、图片、标题/块锚点、高亮以及本地 SVG 公式和 Mermaid 图表，自动打开浏览器后可打印为 PDF；分享 HTML/Markdown 时需携带整个导出文件夹。嵌入笔记暂转为关联文件链接，原始 HTML 不执行，公式与 Mermaid 沿用应用本地渲染器的语法范围，失败保留源码并提示；每篇最多渲染 200 个公式/图表；详见每次生成的“导出说明.txt”。远程图片不下载，HTML 默认阻止其自动加载。

“设置 → 备份与恢复”可选择库外文件夹，手动备份或在应用打开期间每天/每周备份。每次备份包含库内笔记、附件、配置、回收站和空目录，使用普通目录及 SHA-256 清单；不包含库外的应用恢复历史。备份会等待当前保存完成，检测到冲突、符号链接或复制期间内容变化时失败并保留原文件。恢复前重新校验全部文件，只创建新的笔记库目录，不覆盖现有目录。备份数量由用户管理，自动失败后至少间隔一小时重试；这不是文件系统事务快照，也不保证物理断电无损。

通过命令面板或笔记的“更多选项 → 查看当前笔记版本历史”按时间浏览保存记录和恢复草稿。支持查看保存前内容、记录内容，以及与打开历史时正文的差异；恢复会创建新笔记并保留原文件与记录。正文按需读取，超过 128 KiB 的预览会明确截断，恢复仍使用完整内容。历史按记录时的文件路径查询，重命名前的记录暂未串联。

Windows 应用数据在 `%LOCALAPPDATA%\Inkstone`。`recovery` 保存 JSON 恢复记录（包含正文），成功记录后缀为 `.saved`，失败 / 崩溃记录为 `.json`。界面提供每篇文件最新恢复草稿，恢复时新建笔记，不覆盖原文件。成功历史默认保留 30 天，并按每库 128 MiB 预算从最旧记录开始清理；每篇笔记至少保留最新成功记录，因此预算是软上限。失败草稿及冲突备份不自动删除。

删除会移动到笔记库的 `.inkstone-trash/<编号>/`，同目录有 `original-path.json`。可在命令面板的“查看回收站”中恢复文件与文件夹；原路径已存在时拒绝覆盖。

冲突时自动保存停止；“另存为副本”可保存当前编辑版本。普通保存错误也会停止自动重试，修复原因后按 Ctrl+S。IME 组词期间不会把预编辑拼音自动保存。macOS/Linux 成功替换的备份标为 `.saved-backup`，随对应成功历史清理；既有 `.external-backup` 保留供人工确认。异常退出仍可能丢失尚未写入恢复区的输入；慢速 IO 或组词期间可能超过一个自动保存周期。

保存错误旁的“比较并处理”以及笔记菜单、命令面板可比较磁盘与本地正文。可选择保留本地并安全保存，或备份本地草稿后采用磁盘版本；比较后本地/磁盘再次变化会拒绝陈旧操作，处理中继续输入也保留新内容。手动合并可在正文编辑器中完成，再重新比较并保留本地；目前没有自动三方合并。

## 实时预览边界

标题与常用文字语法使用源坐标样式；图片、表格、Callout、嵌入、公式及图表使用可变高度展示投影，光标或选区进入时展开源码。表格复用源码 Tab 导航和行列命令，图形采用后台资源缓存。公式较多时打开后先占位，优先绘制当前视口，滚到附近再补齐，屏外公式不立即栅格化。展示、复制、保存和撤销保持原始 Markdown；视觉对齐、原生多 DPI 与富内容性能目标仍待完成验收。

“设置 → 备份与恢复”还可独立调整版本历史的期限（30/90/365 天或不限）和容量（128/512/2048 MiB 或不限）。后续保存维护时清理超过任一限制的成功旧版本；每篇最新记录、未完成草稿及受保护的冲突记录始终保留，因此容量上限不是硬性磁盘配额。整库备份不受此策略影响。


## WebDAV 云同步

打开“设置 → 云同步”，填写已存在的 WebDAV 目录完整地址、用户名与密码（服务商可能要求应用专用密码）。建议使用 HTTPS。点击“测试连接”检查目录访问，再点击“立即同步”。服务器地址与用户名随当前笔记库配置保存。在 macOS 和 Windows 上，保存配置、测试连接或立即同步时会把密码写入本机系统钥匙串，按服务器、用户名和笔记库分开存放，不会写入笔记库或上传到云端。重启或重新打开该笔记库后会自动填回密码。清空密码后保存，会删除钥匙串中的对应项。Linux 暂不保存密码，重启后需重新输入。

所有设备为同一笔记库填写相同目录，不同笔记库使用不同目录。同步会在目录下创建 `inkstone/`，其中 `manifest.json` 的 `version` 字段记录同步格式版本（当前为 `1`），`objects/` 按 SHA-256 存放文件内容。这是墨砚专用同步格式，不会读取该目录下已有的普通 Markdown 文件；新设备需先创建本地空笔记库，再配置同一远端目录并同步。对象并未加密，服务端管理员可以读取内容；HTTPS 保护传输。

- 默认开启自动双向同步：打开已配置的笔记库，以及新建、保存或删除文件后会自动同步。连续修改会等待约 3 秒再合并为一次同步；同步进行中的新改动会在本次结束后再同步。失败或遇到冲突、保存错误时约 1 分钟后重试，也可随时点击“立即同步”。关闭“自动同步”后仅手动同步。同步前等待编辑内容保存；存在笔记冲突或保存错误时先处理错误。
- 首次合并两端的笔记与附件；后续通过上次成功记录识别新增、修改与删除。重命名按新增和删除处理。首次同名不同内容也保留双方版本。
- 双端同时修改同一文件时，本地版本保留原名，云端版本另存为带“云端冲突”和内容校验值的副本，并同步到其他设备。删除与修改冲突时保留修改，设置页会报告冲突路径；可人工合并，再删除不需要的副本并同步。
- 同步只包含非隐藏普通文件，排除隐藏目录/文件、工作区配置、回收站及历史；空目录不单独同步。符号链接不跟随，非法路径、大小写重名和文件/目录冲突会停止同步。
- 单文件不超过 128 MiB，一次需要下载的文件合计不超过 512 MiB；不做流式大文件同步。同步期间可以继续编辑，遇到磁盘变化时沿用现有冲突处理流程保存草稿。
- 服务器需支持 Basic 认证、`PROPFIND`、`MKCOL`、`GET`、`PUT`、强 `ETag`、`If-Match` 和 `If-None-Match`。请求超时或其他设备抢先提交时可重试；不会自动跟随重定向，请填写服务商最终目录地址。连接测试只验证目录访问，完整读写权限在同步时检查。

本地被覆盖或删除的内容保存在原目录的 `.inkstone-sync-*.backup` 隐藏文件中，对应的 `.backup.json` 记录原路径，需人工确认后清理；这些文件不会再次同步。云端旧内容对象也暂不自动清理，容量由用户管理。设备的同步记录保存在应用数据 `recovery/webdav-sync/`，按笔记库、服务器与账号隔离；请不要手工删除或复制这些记录来处理冲突。云端清单意外丢失时会停止已有设备的同步。同步不替代独立备份，建议继续使用“备份与恢复”。

旧版同步目录迁移：先将所有设备更新到使用 `inkstone/` 的版本，再将远端的 `inkstone-v1/` 整个重命名为 `inkstone/`，保留其中的清单和对象文件，应用内配置的远端目录地址不变。检测到旧清单时应用会停止同步并提示迁移；若两个目录同时存在，请先备份并核对内容，不要直接覆盖或合并。
